# 藏经阁 · The docs

藏经阁 is the Scripture Pavilion, where a sect keeps its manuals. Every doc for this repo lives in this
folder. Each line below says what question its doc answers.

A few docs stay beside the code they describe, because scripts or agents read them there. They are
listed under "Kept beside the code".
